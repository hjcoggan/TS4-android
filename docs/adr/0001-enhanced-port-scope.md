# Enhanced port: original behaviour by default, mods after 1.0

The port aims to be the 360 game on PC, with modern settings layered on top. Each setting is an Enhancement that defaults to original behaviour, and Original bugs are kept unless an Enhancement opts out of them. Mod support is designed in from the start, but it ships after 1.0. We rejected a pure faithful port (too little value on PC) and a remaster-first approach (it would lose the faithful reference that the Oracle comparison depends on).
