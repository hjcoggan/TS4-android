# Settings page in ImGui, opened from a native OPTIONS row; native pages after 1.0

The Settings page is the WWE All Stars Dear ImGui page, styled with Top Spin 4's fonts and colours. Players reach it from a PC SETTINGS row added to the game's own main menu, and also with F4 and a pad combo. (The row was first meant for OPTIONS; it moved to the main menu, which has two hidden rows to reuse, docs/research/game-settings.md Addendum 3.) Top Spin 4's menus are PAM's Lua-driven RGui system, not Scaleform, so drawing the pages themselves natively would need a decompressor for the PAM-LZX archives and authored scene and Lua data: an estimated 4–8 weeks at high risk, against 3–5 days for the row alone. The row gives the native entry point players look for, while ImGui keeps the page the same on the Classic and Native renderers. Fully native RGui pages are a post-1.0 goal. An ImGui-only page with no row was rejected because players would never find it from the game's menus.
