# The Launcher is the home screen and shows every setting

Players open the Launcher every time they start the game: first run sets up the disc and Title Update 1, and after that it is a home screen with Play, Settings, Create shortcut, Help and Open logs. Its Settings page shows and edits every setting, remapping and Presets included, built from the game's settings export and written to the same Settings file as the in-game Settings page, which stays. A Direct shortcut starts the game without the Launcher, and the game opens the Launcher when setup is missing. This reverses the game-settings spec, which cut the Launcher down to setup plus the before-start settings (renderer, GPU) and made the in-game page the main place to change settings, so that a Launcher would not stand in the way every time. In use that Launcher looked empty: the owner found no settings and no sign of what it could do, and every comparable launcher (Zelda64Recomp, WWE All Stars, Dolphin, RPCS3) puts Settings next to Play (`docs/research/launcher-ux.md`). Setup-only and no-Launcher (setup inside the game exe, as Unleashed Recompiled does) were rejected for that reason; the Direct shortcut keeps the one-click start the old design wanted. The cost is two surfaces over one settings list, kept in step by reading the export and never keeping a list in the Launcher.
