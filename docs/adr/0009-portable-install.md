# The game is a portable install

Everything the game and the Launcher write lives in the folder that holds `topspin4.exe`: the prepared disc and Title Update 1 (`gamedata`, `updatedata`), the shader cache (`cache`), and the player's settings, saves, achievements, disc art and the game files location file (`userdata`). Logs were already there. Nothing goes to `%APPDATA%` or `%LOCALAPPDATA%`, and under Proton nothing goes to the XDG data folder. Copying the folder copies the whole install, and deleting it removes everything. This reverses the per-user folders of `docs/goals.md` ("Saves and settings: stored in a per-user directory") and of the launcher-ux spec, at the owner's request on 2026-10-28; the game had not been released, so no install is migrated. A build folder the game cannot write to (for example under Program Files) is refused with a message rather than falling back to the user's folders, so an install never ends up split between two places. The player can still move the prepared game files elsewhere with the game files location; the location file stays in `userdata`. The developer scripts keep passing every folder on the command line, which still wins. Saves remain in the game's own format, so Career saves still copy between the Oracle and the port.
