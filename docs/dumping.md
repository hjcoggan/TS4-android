# Dumping your disc

Put the result in `../dump/` (outside the repository). Any one of these works:

- An ISO of the disc (`ts4.iso`), made with a flashed Xbox 360 DVD drive or an RGH/JTAG console.
- The game's files copied from an RGH/JTAG console (for example over FTP from Aurora or
  XeXMenu): the folder containing `default.xex` and the data archives.
- A Games on Demand / installed copy (GOD or STFS container) from the console's drive.

Also note your disc's region and version (title ID and media ID are shown by Aurora/XeXMenu).
